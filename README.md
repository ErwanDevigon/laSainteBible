# La Sainte Bible

Public-domain Bibles, read in the browser: 43 editions in 21 languages, each with its own canon. Compare them side by side, and follow the cross-references — synopsis, Old Testament quotations, fulfillments. The mass page shows the day’s readings. The Qumran scrolls are included under CC BY-NC 4.0.

Arabic, Chinese, Czech, Dutch, English, Finnish, French, German, Greek, Hebrew, Hungarian, Italian, Japanese, Latin, Norwegian, Portuguese, Russian, Serbian, Spanish, Swedish, Tagalog.
